# Julian House of Fashion Academy (`jhfacademy.com.ng`)

Official Next.js (App Router, TypeScript, Tailwind CSS) website for **Julian House of Fashion Academy**, Ilorin, Kwara State, Nigeria — engineered for high local search visibility on **Google Business Profile (Google Map Pack)**.

- **Intermediate Class:** ₦150,000 (3 months)
- **Advanced Class:** ₦200,000 (3 months)

- **Registration Fee:** ₦10,000 (one-time payment)

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm run start
```

## Deploying to GitHub & Vercel (`jhfacademy.com.ng`)

1. Push this repository to GitHub (`git remote add origin ... && git push -u origin main`).
2. Import the repository into [Vercel](https://vercel.com) (Next.js preset is detected automatically).
3. In Vercel Project Settings → **Domains**, add `jhfacademy.com.ng` and `www.jhfacademy.com.ng`.
4. Update DNS records at your `.ng` registrar (`A` record `@ -> 76.76.21.21` and `CNAME` `www -> cname.vercel-dns.com`, or follow Vercel's exact DNS instructions).
5. Update your **Google Business Profile** website URL to `https://jhfacademy.com.ng` and ensure your address matches: `12 Alarape Street, off Basin Road (off Taoheed Road), Ilorin, Kwara State, 234001`.
